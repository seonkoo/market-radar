# A股板块轮动概率雷达 · 手机版（GitHub 自动版）

每天 **北京时间 08:00（盘前）** 和 **15:00（收盘后）** 自动抓取东方财富公开接口，
生成移动端可看的板块资金流向 / 轮动信号 / 高概率埋伏池 / 持仓纪律快照。

## 怎么用
1. 手机浏览器打开 GitHub Pages 地址（仓库启用 Pages 后生成，形如 `https://<用户名>.github.io/market-radar/`）。
2. 打开即拉**实时数据**（手机浏览器直连东方财富，无需服务器）。
3. 实时接口若临时不通，自动回退到**服务器快照** `latest.json`（即每天 08:00/15:00 跑出来的那份）。
4. 想立刻看最新快照：去仓库 `Actions` → 该工作流 → `Run workflow` 手动触发一次。

## 自动机制
- `.github/workflows/daily.yml`：cron `0 0` / `0 7` UTC（= 北京 08:00 / 15:00）+ 手动触发。
- `generate.py`：服务端抓取（指数 / 行业 / 概念 / 个股资金流 / 板块历史），输出 `latest.json` 并归档到 `snapshots/`。
  - 多域名兜底（push2 / push2delay / push2his）+ 重试；单源失败不影响整体。
  - 抓不到就记失败，**不伪造数据**。
- 首次运行会自动通过 `gh api` 启用 Pages（无需手动开）。

## 重要说明（诚实边界）
- **概率 ≠ 预测**：评分是启发式（资金趋势28% + 今日强度20% + 低位20% + 相对强弱16% + 板块广度16%），
  提高的是"提前埋伏到高概率赛道"的能力，并不预知"哪天恰好百亿进场"——单日百亿是爆发当天的后验数据。
- **服务端抓取在 GitHub 海外机器上可能受东方财富限流/地域影响**：若某次快照为空，页面会自动改用你手机浏览器的实时抓取，不影响使用。
- 数据为个人学习用途，不构成任何投资建议。

## 文件
- `index.html` —— 手机版单文件页面（实时抓 + 快照兜底）
- `generate.py` —— 服务端抓取脚本（仅标准库）
- `latest.json` —— 最近一次服务器快照
- `snapshots/` —— 历史快照归档
